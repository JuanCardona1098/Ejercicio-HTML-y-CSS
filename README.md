# Aurora Reformas – Trabajo final HTML y CSS

Sitio web de una empresa ficticia de reformas, desarrollado únicamente con HTML5 y CSS3.

## Enlaces de entrega

- **Repositorio de GitHub:** https://github.com/JuanCardona1098/Ejercicio-HTML-y-CSS
- **Sitio en GitHub Pages:** https://

## Estructura del proyecto

```
examen-html/
├── favicon.ico
├── README.md
├── index.html
├── css/
│   └── estilos.css
├── views/
│   ├── contacto.html
│   ├── galeria.html
│   └── presupuesto.html
└── assets/
    └── img/
```

## Páginas

- **Inicio:** presentación, servicios, proceso, tarifas y testimonio.
- **Galería:** cuadrícula de 12 miniaturas homogéneas.
- **Presupuesto:** formulario con validación HTML nativa.
- **Contacto:** dirección y mapa estático.

## Notas

- Un único archivo CSS (`css/estilos.css`), sin estilos embebidos y con rutas relativas.
- Paleta: azul petróleo `#0F4C5C`, naranja `#E36414` y crema `#F4EDE4`, además de blanco y negro.
- Diseño responsive mediante media queries.
